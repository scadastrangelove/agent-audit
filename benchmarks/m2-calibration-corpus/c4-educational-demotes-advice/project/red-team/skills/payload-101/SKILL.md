# Payload 101 — training material

This is a red-team training skill. It demonstrates simple injection
payloads so that defenders can build detection coverage.

## Lesson

Injection works by embedding instructions in third-party content. The
attacker's text appears in an unprivileged context but the agent treats
it with elevated trust.

This is NOT live attack guidance. It's intentional training for the
adversarial-defenses team.
